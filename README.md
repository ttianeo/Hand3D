# Hand3D - 3D 粒子系统手势控制

一个使用 Three.js 和 MediaPipe Hands 实现的实时交互 3D 粒子系统。通过摄像头检测双手张合来控制粒子群的缩放与扩散。

## ✨ 功能特点

- 🎮 **手势控制**: 通过摄像头实时检测双手张合状态
  - 双手张开 → 粒子扩散
  - 双手握拳 → 粒子收缩
- 🎨 **多种粒子模型**: 
  - ❤️ 爱心
  - 🌸 花朵
  - 🪐 土星
  - 🧘 佛像
  - 🎆 烟花
- 🌈 **颜色自定义**: 通过颜色选择器调整粒子颜色
- 📊 **参数调节**: 可调整粒子数量和大小
- 🖥️ **全屏支持**: 一键进入全屏模式
- 📱 **响应式设计**: 适配不同屏幕尺寸

## 🚀 使用方法

1. 打开 `index.html` 文件（需要本地服务器或直接通过浏览器打开）
2. 点击"启用摄像头"按钮授予摄像头权限
3. 面对摄像头，张开或握紧双手来控制粒子效果
4. 使用左侧控制面板选择不同的粒子模型和颜色

## 🛠️ 技术栈

- **Three.js** - 3D 渲染引擎
- **MediaPipe Hands** - 手部追踪
- **原生 HTML/CSS/JavaScript** - 无需构建工具
